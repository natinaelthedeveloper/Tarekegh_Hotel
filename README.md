# 🏨 Tarekehn Hotel 

A modern, responsive, and feature-rich full-stack web application designed for hotels and guesthouses. Built to showcase rooms, meeting venues, dining options, interactive image galleries, and streamline guest inquiries.

---

## 🔗 Live Demo & Previews

* **Live Site:** [https://tarekeghhotel.netlify.app](https://www.google.com/search?q=https://tarekeghhotel.netlify.app)


---

## ✨ Key Features

* [x] **Responsive Navigation Header:** Mobile-first design with smooth transitions and active section highlighting.
* [x] **Interactive Accommodations Showcase:** Detailed view of available rooms, amenities, pricing, and high-resolution thumbnail galleries.
* [x] **Versatile Venue & Meeting Spaces:** Integrated tech specifications (4K Projector, Wireless Microphones, Surround Sound, High-Speed Wi-Fi).
* [x] **Dynamic Dining & Category Menus:** Interactive food and drink lists with category filtering and lightboxes.
* [x] **Interactive Lightbox Gallery:** Full-screen high-definition image previews powered by Framer Motion animations.
* [x] **Location & Map Integration:** Live map view with contact information and directions.
* [x] **Contact & Booking Module:** Express backend integration with real-time field validation and network error detection.

---

## 🛠️ Tech Stack

### **Frontend**

* **Framework:** React.js (Vite)
* **Styling:** Tailwind CSS v4
* **Animations:** Framer Motion
* **Icons:** Lucide React & React Icons
